# Git Demo Website

Welcome to the **Git Demo Website** repository!

This is a simple demo website created as part of my learning journey to understand and practice **Git and GitHub**. The main purpose of this project is to gain hands-on experience with version control and learn how developers manage and track changes in their code.

## About the Project

This project serves as a beginner-friendly environment to experiment with Git commands and understand how Git works in real-world development workflows.

Through this project, I aim to explore how to:
- Initialize a Git repository.
- Track changes made to project files.
- Stage and commit changes.
- Create and manage branches.
- Merge branches.
- Understand how to view commit history.
- Connect a local repository to GitHub.
- Push and pull changes between local and remote repositories.

## Technologies Used

- **HTML** – For structuring the website.
- **CSS** – For styling and designing the website.
- **Git** – For version control and tracking changes.
- **GitHub** – For hosting the repository and managing the project remotely.

## Learning Objectives

The key objective of this project is to build a strong foundation in Git and GitHub by applying theoretical concepts through practical implementation.

It will also help me understand how version control makes collaboration, project management, and code maintenance easier for developers.
